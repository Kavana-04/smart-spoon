# Smart Spoon - Enhancing Taste Perception Using Electric Stimulation

This project simulates salty and umami tastes using weak electric signals and AI-based personalization. It helps people on sodium-restricted diets enjoy flavorful meals.

## Features
- Electric stimulation for taste simulation
- Personalized taste profiles using ML
- Computer vision-based food recognition
- Sentiment analysis from market data

## Tech Stack
- Python, OpenCV, TensorFlow
- Scikit-learn, NLTK, TextBlob
